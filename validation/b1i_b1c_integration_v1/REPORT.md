# B1I与B1C同时接入PPP（2026-11-10）

用户明确要求B1I与B1C都参与解算，保留B2a；B2b继续排除，IQ的Q码型问题继续暂停。本轮按此要求更改正式源码和当前构建产物，没有按精度结果自动撤销准入，也没有调整R/Q/P0/GIM或粗差门限。

## 实现与交付

- 正式准入同时允许北斗2I（槽0）、1P（槽3），原5P（槽2）保留；7D/7P/7Z在输入准入和PPP内核均排除。B1C指手机实际输出的1P，没有把D/X或IQ Q重标成P。
- 既有内核已经有独立的BDS_C1P接收机码偏差、逐星槽3模糊度、1575.42MHz波长和C1P精确OSB查询，本轮没有新造或共用B1I状态。已测试两种N同时初始化、各自OSB与RCB、OSB过期只撤掉B1C码而保留可初始化的浮点载波。
- PC标准x64/Release/PPP_only.exe已重建；此前标准程序保存在before/standard_PPP_only.exe，旧固定钟段独立EXE/对象和历史结果保持原位。新标准程序分别精确复现两机新版天线完整回放的前120期，仅耗时不同。
