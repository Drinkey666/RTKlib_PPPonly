# 10/25东向米级偏差：进入路径与剩余来源

本轮只处理10/25最新真机数据。参考由用户确认：30.69820588888889°、104.05203827777777°、椭球高459.813m。没有修改参考、R/Q/P0/GIM、抗差阈值、正式代码或手机产品。

## 1. 本轮回答到了哪一层

**已定位东偏的数学进入路径：当前码方程含持续东向空间分量，滤波在前约60秒形成正东偏，之后继续积累。它不是起始位置本来偏东，也不能仅由实时接口、ATX或RTS/NRT文件标签解释。**

**尚未唯一确定物理来源。** 现有证据无法把接收机/传播造成的方向相关码偏差、共享观测模型误差、产品共性误差及参考点到手机天线的偏移完全分开。本轮未发现可立即修改的确定加减号、单位、索引或内存错误。不能将下列“码空间剖面”直接当作正式坐标改正。

## 2. 东偏何时形成

实际成功试更新前后的位置台账：

|时刻，距实时首历元|东向偏差/m|滤波形式标准差E/m|
|---|---:|---:|
|首次更新之前，SPP初始化|-4.5581|—|
|首次更新之后|-0.9418|2.3458|
|约5秒|+0.1219|0.9493|
|30秒|+1.1843|0.4127|
|60秒|+1.6278|0.2943|
|300秒|+1.4669|0.1321|
|600秒|+1.8076|0.0930|
|末历元，约1548秒|+2.1364|0.0567|

首次更新从西偏4.56m拉到西偏0.94m，本身是在靠近参考；不能把所有正东更新都标成错误。真正需要解释的是随后越过零点并维持正偏。形式标准差逐步变小，不等于实际误差达到厘米，也不是独立覆盖率检验。

23份实际滤波矩阵可逐位复算后验x/P。例：第6历元东向更新+0.48076m，其中同次K·v台账的码行+0.37098m、电离层先验+0.10818m、相位+0.00160m。第61历元总东向更新+0.00584m；末历元仍更新+0.000241m。

这些是**同次更新的代数分解，不是整段最终误差份额**。同一先验下移除整组再算，也仅是当前历元局部敏感性：例如第6历元移除码行使本次后验E减少0.36882m，不能据此把伪距永久关闭或声称整段消除0.36882m。

## 3. 不显式使用P0/Q/历史状态因子，码方程仍偏东

对每个实际更新码行，固定其接受集合、实际H和有效R，将所有实际活动的钟差/ISB、接收机公共码偏差、逐星一阶电离层及湿延迟H列投影掉，再用满秩缩放QR求位置空间分量。没有使用伪逆，没有给码偏差添加真值常数。

该诊断去除了**显式状态先验和相位弧历史因子**，但接受集合和实际R仍含原算法历史影响。因此不能把它称为完全不依赖历史的独立GNSS解。

|时间段/s|原始码经现有产品模型改正后的E空间分量/m|实际使用码方程E空间分量/m|
|---|---:|---:|
|0～60|+2.2500|+1.4893|
|60～300|+0.3403|+0.6830|
|300～900|+2.4232|+2.6376|
|900～结束|+2.2684|+2.9125|
|60～结束|+1.9922|+2.4184|

后期原始码模型本身已经指向偏东约2m；因此“只把初值改好”或“仅认为先验锁死”不能完整解释本次现象。

## 4. 已核实的具体改正分量

新物理查询直接读取真机adapter输出的相同信号、相同槽位和时间，不再走另一套RINEX质量规则；匹配全部53383条实际提交码行。查询只在给定参考点调用现有产品与物理辅助函数，**不是完全独立的物理公式认证**。

60秒后，同一投影下的东向分量为：

|分量|E/m|
|---|---:|
|原始P－几何距离＋卫星钟差|+0.41246|
|施加现有码OSB的分量|+1.57918|
|天线改正分量|+0.00013|
|名义对流层改正分量|+0.00039|
|一阶GIM项|约0，落在被投影电离层列空间中|
|原始码的完整名义模型剖面|+1.99216|
|实际使用码方程减去上述原始码模型|+0.42626|
|实际使用码方程合计|+2.41842|

最后的+0.42626m包含平滑及模型点/状态线性化的剩余差异，**没有声称是已独立认证的纯平滑因果效应**。它不是唯一来源，且前60秒该剩余方向反而为西向−0.76068m，不能通过一个固定常数统一扣除。

**OSB分量为正不证明OSB有误。** 上述是改正值在特定观测几何中的投影，不是改正误差。删掉合法改正，可能使某个样本更接近参考，但不构成正确修复。

### RTS BIA是否用错了

本轮事后新下载、覆盖完整观测的官方NRT BIA为`WUM0MGXNRT_20262970700_01D_01D_OSB.BIA`，内部至10/25 07:00 GPST。它是在采集后取得，不代表现场当时可用。

- 冻结原行/H/R，只将码OSB数值替换为该NRT值：E空间分量变化**+0.02027m**。这不足以解释2m，且方向不是自动改善。
- 两份文件GPS C1W/C2W、Galileo C1C/C5Q、北斗C2I/C6I的无电离层码钟零点均约为0，最大约0.000062m。未观察到这些频对“码钟零点错了数米”的证据；这不等于全部相位/天线参考均已认证。
- 进一步完成一次完整1560历元RAW回放：以先前“RTS BIA＋匹配ATX”实验为控制，仅换官方NRT BIA，其他文件/参数不变。全段60秒后水平RMS **2.06665→2.53191m**，末水平 **2.28075→2.59460m**，Q6均1557。没有改善，未替换手机默认。
- 更换整份BIA还会改变其声明触发的天线/码钟参考及可用信号分支，因此这个完整试验不能解释成“仅OSB数值变了”。局部+2厘米与全程结果也不能混用。

事后新取得的RTS轨道/钟差已覆盖本段：实际轨道记录到GPST07:55，钟差到07:58:30。仅做固定参考物理查询，无新的RTS整段PPP。

|---|---:|---:|
|原NRT轨道/钟差|+1.99216|0|

共同有效行50206条；RTS缺失的C02/C03/C04码行在两边同时移除，未偷偷只删一边。原NRT共同集合结果与全集合在本剖面中数值相同，这些单频行在自由电离层消元后没有增加此位置剖面信息。

GPS原始钟差差约11～12m主要是公共零点，不可直接当成11m定位误差；实际诊断已投影钟差/ISB。RTS的轨道框架/COM/APC及全部参考约定未独立认证，因此此比较只能削弱“该次预报轨钟差异单项解释全部东偏”的说法，不能证明所有公共产品正确。

## 5. 代码位置与结论分类

|结论|证据/代码|分类|
|---|---|---|
|输入初始位置在西侧，之后更新越过零点|`position_update_ledger.csv`；`src/ppp.c:2117`位置预测|已确定数值事实，非新初始化错误|
|码方程持续含东向空间分量|实际H/v/R/身份；`src/ppp.c:3627`残差构造|已确定诊断事实，物理来源尚未唯一识别|
|平滑/历史处理会改变该空间模式，且方向随时间不同|`src/ppp.c:1481`、`:1492`；分期剖面|可解释模型行为，不能直接关闭当作修复|
|固定R及历史抗差不消除有符号偏差|`src/ppp.c:959`、`:3263`、`:3679`之后|随机/偏差模型局限；未调整R、Q或门限|
|23次矩阵更新无新的求解假成功证据|原生x/P逐位一致，K方程最大相对残差2.89e-9，K·v增量重建最大4.68e-10m|未发现新数值实现错误；不是全程独立PSD认证|
|改NRT/RTS标签不能直接解决|新下载回执、局部和全程BIA控制|已完成反证范围内的候选排除，非所有产品错误排除|

现有数据支持的剩余解释是：**改正后仍有不能被现有公共码偏差/钟差/逐星一阶电离层/湿延迟吸收的空间码模式，静态滤波在累积它，同时形式P继续缩小。** 接收机/传播方向相关误差、共享模型项及参考点/天线关系仍无法仅凭此单机记录唯一拆分。用户已确认参考，本轮不改参考、不重复索取不存在的同期接收机RINEX，也不把该结论写成“数据质量一定差”。

## 6. 本轮是否可以直接修复

**没有确认可直接改正式模型的确定代码错误。** 不应删除OSB、永久剔G03、放大R/Q或给东坐标减常数。也不再将实时JNI、初始位置朝向、ATX更换、RTS/NRT文件标签作为本段优先重复检查项目。

若后续实施软件候选，需针对**相关且有符号的码偏差与位置的可辨识性**给出独立可验证模型，不能把它当成单历元粗差或单纯随机方差增大。自由添加逐星偏差会吞掉位置信息，尚不能据此直接启用。当前交付是具体进入路径和排除证据，不是已经消除东偏。
