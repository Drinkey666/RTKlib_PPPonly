## 已知限制及其对下一步的影响

1. `PPP_only/ppp_position.c:297` 正常路径每历元尝试当期SPP；`src/ppp.c:2034` 的接收机公共钟差从当前SPP结果重新初始化。这是当前PPP实现及现有回放结果的一部分。它使新息不满足“与当期观测独立预测”的简单噪声学习前提；**不能仅因这一点判定PPP解算本身错误**。普通抗差滤波仍须在同一预测、同一观测集合下做A/C对照，并报告启动期和钟差初始化影响。
2. `src/ppp.c:486` 的VMF3 mapping使用近似系数；`src/gnss_signal_policy.c`、`src/ppp.c:280` 与TXT/RINEX入口的可用信号集合不完全相同。比较A与新抗差模式时必须使用同一入口、同一观测行、同一产品及同一函数模型；跨入口差异另行验证。
3. IFLC频对、完整协方差正定性、多个PPP会话并发、Android/JNI和产品真实发布时间未由上述回放证明。新模式的首个验收范围限定为当前非组合、PC Release x64、TXT与RINEX回放；不得扩写成所有PPP变体均已验证。
4. B是历史算法基线，保留旧周跳生命周期和多重处罚；新抗差算法应以A的必要模型、正确弧段处理和固定Q/R0为共同起点。B继续单独复现，不作为新算法的代码模板。

## 普通抗差滤波的独立验收条件

- 先冻结A/B既有输出作为回归参照；新算法在独立配置下启用，关闭时A/B不得变化。
- 新抗差只作用于当期观测权重；不做信号级跨历元R学习，不更新eta或Q，不由坐标真值反向调权。
- 核对实际矩阵布局：`H`为`nx×nv`列主序，`R`为`nv×nv`；使用调用`filter()`前的`x⁻/P⁻`。若使用标准化新息，分母为`sqrt(hP⁻hᵀ+Rii)`。
- 明确虚拟大气约束、被拒绝行、编辑重试和初始化行的处理；不得把相同一条观测重复当作独立更新。数值失败时保持Phase 1的原子提交和明确失败原因。
- 用人工矩阵、正常观测和人为粗差分别验证权重、增益、后验有限性；再核对TXT/RINEX的有效历元、状态、reject/slip和失败原因。成功标准是行为正确、可复现、可解释，不能只看坐标误差变小。

当前只完成运行准入核对；本文件本身不启用任何新的抗差算法。
